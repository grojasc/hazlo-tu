# Hazlo tú

Herramientas chicas que puedes **usar** o **construir tú mismo** con una IA. Cada una trae:

- la demo funcionando en el navegador,
- el prompt para pedirle a Claude, ChatGPT o Gemini que te arme la tuya,
- el código, abierto, para copiarlo y cambiarlo.

Las publico en LinkedIn. Si quieres que arme otra, cuéntame qué tarea de tu semana te gustaría resolver: [Gonzalo Rojas Chacón](https://www.linkedin.com/in/gonzalo-rojas-chac%C3%B3n-70104a96/).

| # | Herramienta | Úsala | Hazte la tuya |
|---|---|---|---|
| 01 | **Revisor de planillas**: marca lo que confundiría a una IA en tu Excel o CSV (fechas mezcladas, subtotales, códigos sin ceros o redondeados, RUT que no cuadran) y arma un resumen sin tus datos para pegarle a la IA. | [Abrir](https://grojasc.github.io/hazlo-tu/revisor/) | [Prompt](revisor/PROMPT.md) |

## Privacidad

Las herramientas corren en tu navegador. Tus archivos no se suben a ningún servidor ni se envían a una IA. El revisor descarga solo la librería que lee archivos Excel ([SheetJS](https://sheetjs.com)), y solo cuando abres un .xlsx.
